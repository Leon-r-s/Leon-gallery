# BASEに毎日の原画を一括で並べる手順（貼るだけ）

用意したもの（このフォルダ）
- new_items.csv … 76点分の商品名・説明・価格（2,000円）・在庫1・公開
- new_images.zip … 76枚の画像（BASEの決まりで、ファイル名は日付だけの英数字にしてある）
- 一覧_目視用.md … 何が入っているかの一覧

1. BASEの管理画面 → Apps → 「CSV商品管理」をインストール（無料）
2. CSV商品管理 → 「商品の一括登録・編集」
3. new_items.csv と new_images.zip をアップロード
4. ステータスが「完了」になったら、ショップを開いて1点だけ見て確認
5. そのあと、CSV商品管理で「既存の商品情報をダウンロード」（商品ID と 商品コード にチェック）
   → 落ちてきたCSVを base_export.csv という名前でこのフォルダに置く
6. コマンドプロンプトで
   node base-link-csv.js base_upload/base_export.csv
   → ギャラリーサイトの全作品に「BASEで購入する」ボタンが付く
7. GitHub Desktop で Commit → Push

うまくいかなかったら、出たエラーの文をそのまま私に見せて。
価格は全部2,000円にしてある。変えたい日があれば、CSVのその行の「価格」だけ直す。
